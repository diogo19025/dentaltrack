# AGENTS.md

Este projeto usa **[`CLAUDE.md`](CLAUDE.md)** como guia canônico de contexto e onboarding.

Antes de agir, leia, nesta ordem:
1. [`CLAUDE.md`](CLAUDE.md) — status atual, stack, decisões, próximos passos e o que **não** fazer.
2. [`docs/context.md`](docs/context.md) — especificação do produto (o quê/porquê).
3. [`docs/plan.md`](docs/plan.md) — plano de execução (o como: stack, fases, tarefas).

**Resumo de 1 linha:** DentalTrack é um CRM conversacional com agente de IA para clínicas odontológicas; **Fases 0–3 implementadas e validadas ao vivo** (chatbot web E2E · configurações & catálogo · auto-tagging + dashboard/leads com dados reais) — resta a **F4** (QA, fidelidade 1:1, testes E2E e deploy). **MVP em web**; **WhatsApp é plano futuro**.
